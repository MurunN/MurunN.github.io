# SteppeQuest vNext 2.1

- Relay game canvas startup fix: animation re-initializes correctly when the game starts.
- Relay game visual upgrade:

- Mounted archery visual upgrade:
  - more realistic mounted archer silhouette with bow posture
  - improved track depth and environment composition
- General polish aimed at making both games feel more cinematic and readable.
